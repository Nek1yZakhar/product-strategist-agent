# Чек-лист подачи заявки (MGIMO AI Challenge 2026)

Этот документ регламентирует финальную проверку всех обязательных материалов перед отправкой заявки через личный кабинет участника конкурса (дедлайн: 22 ноября 2026 г., 23:59 МСК).

---

## 1. Состав конкурсного пакета

| Элемент сдачи | Формат / Требование | Статус готовности | Файл в репозитории |
| :--- | :--- | :--- | :--- |
| **1. Исходный код агента** | Публичный репозиторий GitHub / GitVerse с чистой историей коммитов и файлом `README.md` с инструкцией по запуску за 5 минут. | Готово к отправке | Корневой репозиторий, `README.md`, `AGENTS.md` |
| **2. Демонстрационный проект** | Сквозной кейс на базе брифа МегаФона («МегаФон Семья»): от формулировки задачи до стратегии, плана валидации и журнала решений. | Готово к отправке | `knowledge/projects/demo-megafon/` |
| **3. Видеозапись работы** | Видео хронометражем $\le 10$ минут (запрос $\to$ работа агента $\to$ варианты $\to$ выбор $\to$ стратегия $\to$ пауза $\to$ возобновление из нового чата). | Сценарий готов | `demo/VIDEO-PLAN.md`, `demo/RUNBOOK.md` |
| **4. PDF-описание проекта** | Документ с архитектурой, реестром моделей, ключевыми промптами, фичами продвинутого уровня, бюджетом затрат и границами применимости. | Шаблон готов | `docs/CONTEXT.md`, `docs/ARCHITECTURE.md`, `scripts/cost_summary.py` |

## 2. Финальный чек-лист самопроверки перед загрузкой

- [ ] В репозитории отсутствуют секретные ключи, пароли и личные токены (проверено по `.gitignore` и `.env.example`).
- [ ] Все внешние ссылки в `findings/*.md` проверены скриптом `python scripts/verify_citations.py` и имеют статус `verified`.
- [ ] Синтетические респонденты снабжены обязательным дисклеймером о генерации гипотез (arXiv:2507.04438).
- [ ] Скрипт учета затрат `python scripts/cost_summary.py` формирует полную сводку по токенам и стоимости в USD и RUB.
- [ ] Сценарий возобновления сессии (`state/STATE-current-task.md`) протестирован в изолированном окне чата.
- [ ] Видеоролик укладывается в лимит 10 минут и демонстрирует все 4 ключевых критерия оценки.
